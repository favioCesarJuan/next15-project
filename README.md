Modern SaaS landing page built with cutting-edge technologies:
- Next.js 15.3 with Turbopack
- React 19
- TypeScript
- Tailwind CSS
- Storybook 8.6 with Testing

Partially inspired by the [SaaS Landing Pages (Figma Community)](https://www.figma.com/design/e9GXeXCNtsQ8bMNpQkOHqJ/Saas-Landing-Pages--Community-?node-id=0-7&t=8Q9oOAZNZQPHE2CC-0) design.

## ✨ Features

- ⚡ Next.js 15.3 with Turbopack
- 🚀 React 19 with latest features
- 🎨 Tailwind CSS v4 with JIT compiler
- 📚 Storybook 8.6 with:
  - 🧪 Testing utilities
  - 🎛 Auto-docs generation
  - 🖥 Vite-powered builds
- 🛠 TypeScript support
- 📱 Fully responsive design
